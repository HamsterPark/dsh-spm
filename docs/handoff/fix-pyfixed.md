## 一、`pyFixed`：去实测之后，报上来的那一条只是三类里的一类

分派单说的是「`pyFixed(-0, n)` 丢负号」。去 CPython 实测时把整个函数对了一遍，
**发现的不止那一条**。

### 1.1 实测口径

`<MAST_ROOT>\.venv-v2-py313\Scripts\python.exe`（CPython **3.13.13**），
`"%.*f" % (n, x)`，**10 843 个 double × 7 档小数位（d = 0…6）= 75 901 格**。
输入集由**构造**而来，不由抽样而来：

* 全部 `n/2^k`（k = 1…13、n = 1…39，正负各一份）—— 真半分点的全部来源；
* 每一档 `d` 的十进制半分点 `0.5·10^-d + k·10^-d`（k = 0…11，正负）；
* `±10^-e`（e = 0…39）—— 逼出「舍入之后变成零、符号还在」；
* 4 000 个随机 dyadic `n/2^k` + 6 000 个跨量级随机 double（`random.Random(20260919)`）；
* 手工反例 `2.675 / 2.665 / 1.115 / 0.155 / 0.165 / 8.835 / 0.0625 / 0.1875 / 248.85 …`。

**改前 70 格不一致；改后 0 格。**

### 1.3 改了什么

```ts
export function pyFixed(v: number, digits: number): string {
  if (!Number.isFinite(v)) return Number.isNaN(v) ? 'nan' : v > 0 ? 'inf' : '-inf'
  const sign = v < 0 || Object.is(v, -0) ? '-' : ''      // ① 符号来自输入
  const a = Math.abs(v)
  const halves = a * 2 ** (digits + 1)                    // ② 纯指数平移，不舍入
  if (Number.isInteger(halves) && halves % 2 === 1) {
    const p = 10 ** digits
    const fl = Math.floor(a * p)
    return sign + ((fl % 2 === 0 ? fl : fl + 1) / p).toFixed(digits)
  }
  return sign + a.toFixed(digits)
}
```

### 1.4 与 `formatG` 是同一个坑

`si.ts:57` 早就为 `formatG` 立过规矩，逐字：

> **负零保号**：Python 的 `f"{-0.0:g}"` 是 `-0`，而 JS 的 `String(-0)` 是 `0`。
> 一个 `-0` 出现在界或读数里，多半意味着上游做了一次乘负或取反 ——
> 把符号擦掉，就把那条线索也擦掉了。

`pyFloatRepr`（`si.ts:220`）也有同一道守卫，注释就写着「同 `formatG`」。
**三份里两份有、一份没有** —— 而分辨它们的唯一办法是找一个能把它们分开的输入。

② 那一类同理：`pyRound` 用 `toFixed(20)` 判精确半分点并写了三段注释解释为什么不能用乘法，
`pyFixed` 隔壁写着相反的断言活到今天。**一族里的成员各自为政，第六个和第七个就会互相拆台。**
