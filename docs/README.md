## 选择运行方式

两种入口都使用 dsh 原生模型会话，工具目录和模拟器生命周期各自独立。

| 你的环境 | 指南 | 运行方式 |
|---|---|---|
| 有 STM-Bench 源码和 Python 环境 | [受管 STM-Bench](MINIMUM-USABLE.md) | 插件启动并停止本轮模拟器；模型工具为 hello / GetBias |
| Windows 上已有 Nanonis Mimea + STM Simulator | [本机 Nanonis 模拟器](NANONIS-SIMULATOR.md) | 核验进程身份后连接；支持有限读取、偏压设置和扫描启停，退出不关闭外部模拟器 |

每份指南包含安装、参数配置、验收和关闭步骤。只想检查仓库时，可先执行首页的构建及单元／契约命令，无需模拟器或模型密钥。
